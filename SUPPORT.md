# Getting Help / دریافت راهنمایی

**فارسی:** اگر به کمک نیاز دارید، به ترتیب زیر پیش بروید — بیشتر پاسخ‌ها در
مستندات موجود هستند. اگر جواب را پیدا نکردید، یک issue باز کنید.

**English:** Work through the list below — most answers already live in the
docs. If you can't find yours, open an issue.

## 2. Check the known issues / مشکلات شناخته‌شده

Search the [issue tracker](https://github.com/ahmad75naraghi/wp-ai-post-creator/issues?q=is%3Aissue)
before opening a new issue — your problem may already be reported (and maybe
even fixed for the next release).

## 3. Open an issue / باز کردن issue

Use the issue templates — they ask for exactly what a useful report needs:

- [🐛 Report a bug](https://github.com/ahmad75naraghi/wp-ai-post-creator/issues/new?template=bug_report.md)
  — please attach the **job log** (AI Post Creator → Logs → the job's detail
  page) and your environment (WordPress / PHP / plugin versions). The job log
  records every step, API call and error, and usually pinpoints the cause
  immediately. Never post API keys; if a key leaked into a log, see the
  security policy below.
- [✨ Request a feature](https://github.com/ahmad75naraghi/wp-ai-post-creator/issues/new?template=feature_request.md)

## 4. Security / مسائل امنیتی

Vulnerabilities are reported **privately** via
[GitHub security advisories](https://github.com/ahmad75naraghi/wp-ai-post-creator/security/advisories/new) —
never in a public issue. See [SECURITY.md](SECURITY.md).

## 5. Contributing / مشارکت در توسعه

Code, docs and translations are welcome — start with
[CONTRIBUTING.md](CONTRIBUTING.md).
